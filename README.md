# Bio-Engine：程序化生物动画

一个充满想象力的程序化生物动画项目，邀请你用代码创造会动的生命！

## 项目愿景

这不是一个"按照规格实现"的项目，而是一个**启发创造力**的画布。我们提供概念和思路，你用代码把它们变成现实——每个实现都可以是独特的。

## 它是什么？

想象一下：
- 用算法定义规则，而不是画每一帧
- 生物有自己的行为，你是规则的设计者
- 每次运行都可能有惊喜
- 无限的变化可能性

## 没有"标准答案"

这个项目鼓励：
- 🎨 独特的视觉风格
- 🧠 不同的算法思路
- 🎮 有趣的交互方式
- ✨ 你自己的想象力
