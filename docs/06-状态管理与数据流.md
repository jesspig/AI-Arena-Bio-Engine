# 状态管理与数据流

## 1. 全局状态定义

### 1.1 状态结构

系统使用 React Context + useReducer 管理全局状态，状态为不可变对象。

```mermaid
classDiagram
    class CreatureConfig {
        +string id
        +number spineCount
        +number segLength
        +number legCount
        +number[] legSegments
        +number speed
        +string color
        +Vec2 | null target
        +boolean isSelected
        +number[] autoTargetRange
    }
    
    class CreatureState {
        +CreatureConfig[] creatures
        +string | null selectedId
    }
    
    class CreatureAction {
        +string type
        +string id
        +Vec2 target
        +Partial<CreatureConfig> config
    }
    
    CreatureState --> CreatureConfig

### 1.2 状态属性详解

| 属性      | 类型           | 说明                                     |
| --- | --- | --- |
| creatures | CreatureConfig[] | 生物配置对象数组                       |
| selectedId | string \| null | 当前选中生物的 ID，null 表示未选中任何生物 |

### 1.3 CreatureConfig 属性详解

| 属性          | 类型           | 范围                    | 说明                                     |
| --- | --- | --- | --- |
| id            | string         | -                       | 生物唯一标识，使用 UUID 或时间戳生成     |
| spineCount    | number         | 3~30                    | 脊柱节点总数                             |
| segLength     | number         | 10~50                   | 体节间距（像素）                         |
| legCount      | number         | 0~8                     | 腿部数量                                 |
| legSegments   | number[]       | [5, 50]                 | 股骨和胫骨长度元组                       |
| speed         | number         | 1~10                    | 头部追逐速度（像素/帧）                  |
| color         | string         | #000000~#ffffff         | 生物颜色                                 |
| target        | Vec2 \| null   | -                       | 目标点坐标，null 表示无目标              |
| isSelected    | boolean        | -                       | 是否被用户选中                           |
| autoTargetRange | number[]     | [xMin, yMin, xMax, yMax] | 自动漫游范围                           |

## 2. Action 类型定义

### 2.1 Action 联合类型

```mermaid
graph TD
    A[CreatureAction] --> B[ADD_CREATURE]
    A --> C[REMOVE_CREATURE]
    A --> D[SELECT_CREATURE]
    A --> E[SET_TARGET]
    A --> F[UPDATE_CONFIG]
    
    B --> B1[无参数]
    C --> C1[id: string]
    D --> D1[id: string | null]
    E --> E1[id: string, target: Vec2]
    F --> F1[id: string, config: Partial<CreatureConfig>]
```text

### 2.2 Action 详细说明

| Action 类型     | 参数                                      | 说明                                           |
| --- | --- | --- |
| ADD_CREATURE    | 无                                        | 添加新生物，使用默认配置                       |
| REMOVE_CREATURE | id: string                                | 删除指定 ID 的生物                             |
| SELECT_CREATURE | id: string \| null                        | 选中生物，传入 null 表示取消选中               |
| SET_TARGET      | id: string, target: Vec2                  | 为指定生物设置移动目标                         |
| UPDATE_CONFIG   | id: string, config: Partial\<CreatureConfig\> | 更新生物的部分配置参数                       |

## 3. Reducer 设计

### 3.1 Reducer 函数签名

```typescript
reducer(state: CreatureState, action: CreatureAction): CreatureState
```text

### 3.2 纯函数特性

- **输入**：当前状态 + Action
- **输出**：新状态（不可变）
- **副作用**：无
- **可测试性**：相同输入始终返回相同输出

### 3.3 Action 处理流程图

```mermaid
flowchart TD
    A[reducer 调用] --> B{action.type}
    B -->|ADD_CREATURE| C[生成新生物配置]
    C --> D[添加到 creatures 数组]
    D --> E[返回新状态]
    
    B -->|REMOVE_CREATURE| F[过滤 creatures 数组]
    F --> G[删除对应 ID 的生物]
    G --> H{selectedId == 被删除 ID?}
    H -->|是| I[设置 selectedId = null]
    H -->|否| J[保持 selectedId]
    I --> E
    J --> E
    
    B -->|SELECT_CREATURE| K[遍历 creatures 数组]
    K --> L[设置对应 id 的 isSelected = true]
    L --> M[其他生物 isSelected = false]
    M --> N[更新 selectedId]
    N --> E
    
    B -->|SET_TARGET| O[找到对应 id 的生物]
    O --> P[更新其 target 属性]
    P --> E
    
    B -->|UPDATE_CONFIG| Q[找到对应 id 的生物]
    Q --> R[合并 config 到现有配置]
    R --> E
```mermaid

## 4. Context 设计

| --- | --- | --- |

## 5. 从 React 到 p5 的数据流

### 5.1 数据流时序图

```mermaid
sequenceDiagram
    participant UI as UI 组件
    participant Ctx as CreatureContext
    participant Rdc as Reducer
    participant Hk as useCreatureSketch
    participant P5 as p5 Sketch
    participant Cr as Creature 实例
    
    UI ->> Ctx: dispatch Action
    Ctx ->> Rdc: (state, action)
    Rdc ->> Rdc: 计算新状态
    Rdc ->> Ctx: 返回新 state
    Ctx ->> Ctx: 广播状态更新
    Ctx ->> Hk: Context 值变化
    Hk ->> P5: updater 机制同步
    P5 ->> Cr: 读取新配置
    Cr ->> Cr: 应用新参数
    Cr -->> P5: 更新完成
```text

### 5.2 数据流关键点

| 环节       | 机制       | 说明                                   |
| --- | --- | --- |
| UI 触发    | dispatch   | 用户操作触发 Action 派发               |
| 状态更新   | Reducer    | 纯函数计算新状态                       |
| 状态广播   | Context    | React Context 自动通知订阅者           |
| Hook 接收  | useContext | 自定义 Hook 获取最新状态               |
| p5 同步    | updater prop | @p5-wrapper/react v5 机制            |
| 实例应用   | Creature 读取 | 每帧 draw 循环读取最新配置          |

## 6. 从 p5 到 React 的数据流

### 6.1 数据流时序图

```mermaid
sequenceDiagram
    actor 用户
    participant P5 as p5 Sketch
    participant Cb as 事件回调
    participant Ctx as CreatureContext
    participant Rdc as Reducer
    participant Cr as Creature 实例
    
    用户 ->> P5: 右键点击画布
    P5 ->> Cb: mousePressed 事件
    Cb ->> Cb: 检测 selectedId 非空
    Cb ->> Ctx: dispatch(SET_TARGET, id, target)
    Ctx ->> Rdc: (state, action)
    Rdc ->> Rdc: 更新对应生物的 target
    Rdc ->> Ctx: 返回新 state
    Ctx ->> Ctx: 广播状态更新
    Ctx ->> P5: updater 机制同步
    P5 ->> Cr: 新 target 生效
    Cr ->> Cr: 头部追逐新目标
```mermaid

### 6.2 事件回调闭包

```mermaid
graph TD
    A[useCreatureSketch Hook] --> B[创建 sketch 函数]
    B --> C[通过闭包捕获 dispatch]
    B --> D[通过闭包捕获 selectedId]
    B --> E[通过闭包捕获 creatures]
    C --> F[mousePressed 回调]
    D --> F
    E --> F
    F --> G[dispatch SET_TARGET]
```text

**闭包作用**：

- sketch 函数通过闭包访问最新的 React 状态
- 无需将状态作为参数显式传递
- 确保事件回调能正确派发 Action

## 7. 状态不可变性

### 7.1 不可变更新模式

```mermaid
graph TD
    A[旧状态 state] --> B[创建新对象]
    B --> C[复制未修改字段]
    C --> D[设置修改字段]
    D --> E[返回新状态]
    
    style A fill:#ff9999
    style E fill:#99ff99
```text

### 7.2 不可变更新示例

| 操作       | 旧状态                    | 新状态                            |
| --- | --- | --- |
| 设置 target | { target: null }          | { target: { x: 100, y: 100 } }    |
| 更新 speed | { speed: 5 }              | { speed: 8 }                      |
| 选中生物   | { isSelected: false }     | { isSelected: true }              |

**关键规则**：

- 不直接修改原状态对象
- 使用对象展开运算符或 Object.assign 创建新对象
- 数组操作使用 filter、map 等返回新数组的方法

## 8. 数据流优化

### 8.1 React.memo 优化

```mermaid
graph TD
    A[Context 状态变化] --> B{组件使用 memo?}
    B -->|是| C{依赖的 props 变化?}
    B -->|否| D[重新渲染]
    C -->|是| D
    C -->|否| E[跳过渲染]
```mermaid

### 8.2 useCallback 优化

| 优化项       | 说明                                   |
| --- | --- |
| 事件回调缓存 | 使用 useCallback 缓存鼠标点击回调     |
| 依赖数组     | 仅在 selectedId 变化时重新创建回调     |
| 避免闭包重建 | 每帧不重新创建闭包函数                 |

### 8.3 dispatch 传递优化

| 方式                 | 优点                                   | 缺点                                       |
| --- | --- | --- |
| 传递整个 context value | 简单                                   | 任何状态变化都触发重渲染                   |
| 单独传递 dispatch    | 高效                                   | dispatch 引用稳定，不会触发重渲染         |

**推荐方式**：单独传递 dispatch，避免不必要的重渲染。

## 9. 状态调试

### 9.1 时间旅行调试

```mermaid
graph TD
    A[初始状态 S0] --> B[Action A1]
    B --> C[状态 S1]
    C --> D[Action A2]
    D --> E[状态 S2]
    E --> F[Action A3]
    F --> G[状态 S3]
    
    G -.->|撤销| C
    G -.->|重放| E
```text

**时间旅行优势**：

- useReducer 记录所有 Action 历史
- 可回退到任意历史状态
- 便于调试和复现问题

### 9.2 状态日志

| 日志项 | 说明 |
| --- | --- |
| Action 类型 | 记录每次派发的 Action 类型 |
| 状态快照 | 记录 Action 执行前后的状态 |
| 性能指标 | 记录 Reducer 执行时间 |

## 10. 测试用例设计

### 10.1 Reducer 测试

| 测试项 | 输入 | 预期输出 |
| --- | --- | --- |
| ADD_CREATURE | state + { type: ADD_CREATURE } | creatures 数组长度 +1 |
| REMOVE_CREATURE | state + { type: REMOVE_CREATURE, id } | creatures 数组移除对应 id |
| SELECT_CREATURE | state + { type: SELECT_CREATURE, id } | 对应生物 isSelected = true，其他为 false |
| SET_TARGET | state + { type: SET_TARGET, id, target } | 对应生物 target 更新 |
| UPDATE_CONFIG | state + { type: UPDATE_CONFIG, id, config } | 对应生物配置合并更新 |

### 10.2 边界条件测试

| 测试项 | 输入 | 预期输出 |
| --- | --- | --- |
| 删除不存在的 ID | REMOVE_CREATURE, id=不存在 | 状态不变 |
| 选中不存在的 ID | SELECT_CREATURE, id=不存在 | selectedId = null |
| 空 creatures 数组 | 任何 Action | 正常处理，不报错 |
| 并发 Action | 连续派发多个 Action | 按顺序依次处理 |
