# 参数化设计

## 1. 参数化设计原则

系统遵循彻底的参数化设计，所有核心行为均可通过配置灵活调整，无需修改核心逻辑代码。

### 1.1 设计目标

| 目标 | 说明 |
| --- | --- |
| 灵活性 | 所有关键行为参数可配置 |
| 可预测性 | 参数范围明确，行为可预测 |
| 安全性 | 参数越界时有防御性处理 |
| 即时性 | 参数调整立即生效，无需重启 |

### 1.2 参数分类

```mermaid
graph TD
    A[参数分类] --> B[脊柱形态参数]
    A --> C[腿部参数]
    A --> D[运动参数]
    A --> E[视觉效果参数]
    
    B --> B1[spineCount]
    B --> B2[segLength]
    
    C --> C1[legCount]
    C --> C2[legSegments]
    
    D --> D1[speed]
    D --> D2[constraintIterations]
    D --> D3[liftThreshold]
    
    E --> E1[color]
    E --> E2[autoTargetRange]
```text

## 2. 脊柱形态参数

### 2.1 spineCount（脊柱节点总数）

| 属性 | 值 |
| --- | --- |
| 类型 | number |
| 范围 | 3~30 |
| 默认值 | 10 |
| 单位 | 个 |
| 说明 | 脊柱链中的节点总数，包括头部节点 |

#### 参数影响

| spineCount 值 | 视觉效果 | 性能影响 |
| --- | --- | --- |
| 3 | 极短链，几乎无拖拽感 | 最优 |
| 5~10 | 中等长度，拖拽效果明显（推荐） | 良好 |
| 15~20 | 较长链，柔性好 | 中等 |
| 25~30 | 极长链，高度柔性 | 稍慢 |

### 2.2 segLength（体节间距）

| 属性 | 值 |
| --- | --- |
| 类型 | number |
| 范围 | 10~50 |
| 默认值 | 20 |
| 单位 | 像素 |
| 说明 | 相邻两个脊柱节点之间的距离 |

#### 参数影响

| segLength 值 | 视觉效果 | 适用场景 |
| --- | --- | --- |
| 10~15 | 节点密集，链式紧凑 | 小型生物 |
| 20~30 | 中等间距，自然效果（推荐） | 通用场景 |
| 35~50 | 节点稀疏，链式拉伸 | 大型生物 |

## 3. 腿部参数

### 3.1 legCount（腿数量）

| 属性 | 值 |
| --- | --- |
| 类型 | number |
| 范围 | 0~8 |
| 默认值 | 4 |
| 单位 | 个 |
| 说明 | 生物拥有的腿部总数 |

#### 参数影响

| legCount 值 | 生物类型 | 视觉效果 |
| --- | --- | --- |
| 0 | 蛇类 | 无腿部，只有脊柱蠕动 |
| 2 | 双足生物 | 不稳定，跳跃式移动 |
| 4 | 四足生物 | 稳定步态（推荐） |
| 6 | 六足昆虫 | 昆虫步态 |
| 8 | 多足生物 | 蜈蚣式步态 |

### 3.2 legSegments（骨骼长度数组）

| 属性 | 值 |
| --- | --- |
| 类型 | number[] |
| 范围 | [5, 50] |
| 默认值 | [20, 15] |
| 单位 | 像素 |
| 说明 | 元组类型，第一个值为股骨长度 l1，第二个值为胫骨长度 l2 |

#### 参数影响

| 配置 | 视觉效果 | 适用场景 |
| --- | --- | --- |
| [10, 10] | 短腿，贴地移动 | 小型生物 |
| [20, 15] | 中等腿长，自然步态（推荐） | 通用场景 |
| [30, 25] | 长腿，高抬腿移动 | 大型生物 |
| [l1 >> l2] | 股骨主导 | 特殊形态 |
| [l1 << l2] | 胫骨主导 | 特殊形态 |

## 4. 运动参数

### 4.1 speed（头部追逐速度）

| 属性 | 值 |
| --- | --- |
| 类型 | number |
| 范围 | 1~10 |
| 默认值 | 5 |
| 单位 | 像素/帧 |
| 说明 | 头部节点每帧向目标点移动的最大距离 |

#### 参数影响

| speed 值 | 移动速度 | 视觉效果 |
| --- | --- | --- |
| 1~2 | 极慢 | 悠闲漫游 |
| 3~5 | 中等速度（推荐） | 自然移动 |
| 6~8 | 快速 | 敏捷生物 |
| 9~10 | 极快 | 瞬间移动感 |

### 4.2 constraintIterations（距离约束迭代次数）

| 属性 | 值 |
| --- | --- |
| 类型 | number |
| 范围 | 2~5 |
| 默认值 | 3 |
| 单位 | 次 |
| 说明 | 每帧执行距离约束求解的迭代次数 |

#### 参数影响

| iterations 值 | 约束精度 | 性能 |
| --- | --- | --- |
| 2 | 基本约束，轻微误差 | 最优 |
| 3 | 平滑约束，误差小（推荐） | 平衡 |
| 4 | 极佳约束，几乎无误差 | 稍慢 |
| 5 | 边际收益递减 | 不推荐 |

### 4.3 liftThreshold（抬腿检测距离阈值）

| 属性 | 值 |
| --- | --- |
| 类型 | number |
| 范围 | 30~60 |
| 默认值 | 40 |
| 单位 | 像素 |
| 说明 | 附着点与脚部距离超过此值时触发抬脚 |

#### 参数影响

| liftThreshold 值 | 抬脚频率 | 视觉效果 |
| --- | --- | --- |
| 30 | 频繁抬脚 | 高步频，小步幅 |
| 40 | 中等频率（推荐） | 自然步态 |
| 50~60 | 较少抬脚 | 低步频，大步幅，腿部拖拽 |

## 5. 视觉效果参数

### 5.1 color（生物颜色）

| 属性 | 值 |
| --- | --- |
| 类型 | string |
| 格式 | #RRGGBB 十六进制 |
| 默认值 | #ffffff |
| 说明 | 生物的绘制颜色 |

#### 预设色板

| 色值 | 名称 | 适用场景 |
| --- | --- | --- |
| #ffffff | 白色 | 默认，高对比度 |
| #4a9eff | 蓝色 | 水生生物 |
| #2ecc71 | 绿色 | 陆地生物 |
| #e74c3c | 红色 | 危险/敌对生物 |
| #f39c12 | 橙色 | 温暖/友好生物 |
| #9b59b6 | 紫色 | 神秘生物 |

### 5.2 autoTargetRange（自动漫游范围）

| 属性 | 值 |
| --- | --- |
| 类型 | number[] |
| 格式 | [xMin, yMin, xMax, yMax] |
| 默认值 | [50, 50, width-50, height-50] |
| 单位 | 像素 |
| 说明 | 定义自动漫游时目标点生成的安全区域 |

#### 边界计算

xMin = 50（左边距）
yMin = 50（上边距）
```text
xMax = 画布宽度 - 50（右边距）
yMax = 画布高度 - 50（下边距）
```text

**安全区域作用**：确保生成的目标点不会太靠近画布边缘，避免生物被裁剪。

## 6. 参数约束与验证

### 6.1 参数约束表

| 参数 | 最小值 | 最大值 | 类型约束 | 越界处理 |
| --- | --- | --- | --- | --- |
| spineCount | 3 | 30 | 整数 | 钳制到有效范围 |
| segLength | 10 | 50 | 正数 | 钳制到有效范围 |
| legCount | 0 | 8 | 整数 | 钳制到有效范围 |
| legSegments[0] | 5 | 50 | 正数 | 钳制到有效范围 |
| legSegments[1] | 5 | 50 | 正数 | 钳制到有效范围 |
| speed | 1 | 10 | 正数 | 钳制到有效范围 |
| constraintIterations | 2 | 5 | 正整数 | 钳制到有效范围 |
| liftThreshold | 30 | 60 | 正数 | 钳制到有效范围 |
| autoTargetRange | - | - | 四元素数组 | 验证 xMin < xMax, yMin < yMax |

### 6.2 参数依赖关系

| 依赖关系 | 说明 |
| --- | --- |
| spineCount > legCount | 脊柱节点数应大于腿数量，确保腿部有附着点 |
| segLength * spineCount < 画布尺寸 | 脊柱总长度不应超过画布尺寸 |
| l1 + l2 > liftThreshold | 骨骼总长应大于抬脚阈值，否则腿无法正常移动 |

## 7. 参数配置界面

### 7.1 Sidebar 控件映射

```mermaid
graph TD
    A[Sidebar] --> B[脊柱段数滑块 - spineCount]
    A --> C[体节间距滑块 - segLength]
    A --> D[腿数量滑块 - legCount]
    A --> E[股骨长度滑块 - legSegments[0]]
    A --> F[胫骨长度滑块 - legSegments[1]]
    A --> G[移动速度滑块 - speed]
    A --> H[颜色选择器 - color]
    A --> I[应用按钮]
    
    B --> I
    C --> I
    D --> I
    E --> I
    F --> I
    G --> I
    H --> I
    I --> J[dispatch UPDATE_CONFIG]
```text

| 胫骨长度 | input[type=range] | value, min=5, max=50, step=1 | onChange 更新本地状态 |
| 移动速度 | input[type=range] | value, min=1, max=10, step=0.5 | onChange 更新本地状态 |

| 应用 | button | onClick | dispatch UPDATE_CONFIG |

## 8. 参数化扩展

### 8.1 未来可扩展参数

| 参数 | 说明 | 预期效果 |
| --- | --- | --- |
| gravity | 重力加速度 | 影响腿部抬脚和落地 |
| damping | 阻尼系数 | 影响脊柱链的惯性效果 |
| stepHeight | 抬脚高度 | 控制脚部抬起的最大高度 |
| tailCount | 尾部数量 | 支持多尾部生物 |
| eyePosition | 眼睛位置 | 在头部添加视觉器官 |

| 蜈蚣 | spineCount=30, legCount=8, speed=4 | 长链多足 |
| 蜥蜴 | spineCount=12, legCount=4, speed=5 | 四足爬行动物 |
| 毛毛虫 | spineCount=15, legCount=6, speed=2 | 缓慢蠕动 |
