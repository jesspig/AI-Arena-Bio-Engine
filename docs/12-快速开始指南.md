# 快速开始指南

## 1. 项目初始化

### 1.1 环境要求

| 工具 | 最低版本 | 推荐版本 | 说明 |
| --- | --- | --- | --- |
| Node.js | 18.x | 20.x LTS | JavaScript 运行时 |
| npm | 9.x | 10.x | 包管理器 |
| 浏览器 | Chrome 100+ | Chrome 最新版 | p5.js 运行环境 |

### 1.2 创建项目

```bash
npm create vite@latest bio-engine -- --template react-ts
cd bio-engine
npm install @p5-wrapper/react@^5 p5
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```text

### 1.3 安装依赖说明

| 依赖 | 类型 | 用途 | 推荐版本 |
| --- | --- | --- | --- |
| react | 生产依赖 | 前端框架 | 19.x |
| react-dom | 生产依赖 | React DOM 渲染 | 19.x |

## 2. 样式配置

### 2.1 Tailwind v4 配置

Tailwind CSS v4 采用 CSS-first 配置方式，无需 `tailwind.config.js`：

```css
/* src/index.css */
@import "tailwindcss";

@theme {
  --color-surface: #0a0a0a;
  --color-panel: #1a1a1a;
  --color-panel-hover: #2a2a2a;
  --color-accent: #4a9eff;
  --color-text-primary: #ffffff;
  --color-text-secondary: #a0a0a0;
  --color-border: #333333;
}
```

### 2.2 Vite 配置

Vite 6 需使用 `@tailwindcss/vite` 插件：

```typescript
// vite.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
```

### 3.2 核心类型

| 类型 | 说明 |
| --- | --- |
| Vec2 | 二维坐标结构，包含 x 和 y 两个数值字段 |
| CreatureConfig | 生物配置接口，包含 id、spineCount、segLength、legCount、legSegments、speed、color、target、isSelected、autoTargetRange |
| CreatureAction | 联合类型，覆盖五种操作：ADD_CREATURE、REMOVE_CREATURE、SELECT_CREATURE、SET_TARGET、UPDATE_CONFIG |

## 4. 核心实现流程

### 4.1 步骤总览

```mermaid
flowchart TD
    A[1. 建立目录结构] --> B[2. 实现引擎层]
    B --> C[3. 实现状态管理层]
    C --> D[4. 实现适配层]
    D --> E[5. 实现界面层]
    E --> F[6. 运行开发服务器]
```text

### 4.2 详细步骤

#### 步骤 1：建立目录结构

按照 `src/` 目录结构建立以下文件夹：

- `src/engine/` - 引擎层
- `src/state/` - 状态管理层
- `src/hooks/` - 适配层
- `src/components/` - 界面层
- `src/types/` - 类型定义

#### 步骤 2：实现引擎层

在 `src/engine/` 下实现以下文件：

| 文件 | 职责 | 参考文档 |
| --- | --- | --- |
| Spine.ts | 脊柱链式约束：距离约束求解、头部追逐 | 03-核心引擎设计-脊柱算法 |
| Leg.ts | 反向运动学：二关节解析求解、贴地逻辑 | 04-核心引擎设计-IK肢体算法 |
| Creature.ts | 生物主体：数据聚合与行为编排 | 05-Creature行为编排与自动漫游 |

#### 步骤 3：实现状态管理层

在 `src/state/` 下实现以下文件：

| 文件 | 职责 | 参考文档 |
| --- | --- | --- |
| reducer.ts | useReducer 纯函数 + Action 定义 | 06-状态管理与数据流 |
| CreatureContext.tsx | Context Provider 与 Hook 导出 | 06-状态管理与数据流 |

#### 步骤 4：实现适配层

在 `src/hooks/` 下实现以下文件：

| 文件 | 职责 | 参考文档 |
| --- | --- | --- |
| useCreatureSketch.ts | 封装 sketch 函数与交互回调 | 08-交互机制设计 |

#### 步骤 5：实现界面层

在 `src/components/` 下实现以下文件：

| 文件 | 职责 | 参考文档 |
| --- | --- | --- |
| Layout.tsx | 三列布局容器 | 07-UI组件设计 |
| CanvasPanel.tsx | p5 画布容器（P5Canvas 包装） | 07-UI组件设计 |
| Sidebar.tsx | 左侧配置面板（滑块、按钮、创建/删除） | 07-UI组件设计 |
| CreatureList.tsx | 右侧生物列表（选中、删除） | 07-UI组件设计 |

#### 步骤 6：运行开发服务器

```bash
npm run dev
```text

## 5. 开发工作流

### 5.1 日常开发流程

```mermaid
flowchart TD
    A[修改代码] --> B[保存文件]
    B --> C[Vite HMR 热更新]
    C --> D[浏览器自动刷新]
    D --> E[验证修改效果]
    E --> F{满意?}
    F -->|否| A
    F -->|是| G[提交代码]
```mermaid

### 5.2 调试技巧

| 调试目标 | 工具 | 说明 |
| --- | --- | --- |
| React 状态 | React Developer Tools | 查看 Context 状态和组件树 |
| p5 画布 | 浏览器控制台 | 查看 p5 实例和绘制状态 |
| 性能分析 | Chrome DevTools Performance | 分析帧率和 GC 情况 |
| 类型检查 | TypeScript 编译器 | 查看类型错误 |

### 5.3 常见问题排查

| 问题 | 可能原因 | 解决方式 |
| --- | --- | --- |
| 画布不显示 | p5 未正确初始化 | 检查 @p5-wrapper/react 安装 |
| 生物不移动 | target 为 null | 确认自动漫游或手动控制触发 |
| 状态不同步 | updater 未正确传递 | 检查 CanvasPanel 的 updater prop |
| 类型错误 | TypeScript 严格模式 | 运行 `tsc --noEmit` 查看错误 |
