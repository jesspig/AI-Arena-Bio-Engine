# 交互设计

思考用户如何与你的生物互动，创造有趣的体验。

---

## 交互模式的多种可能

### 模式 A：直接控制 - 像牵线木偶

用户直接操作生物，生物立即响应。

```
用户抓住生物头部 → 生物跟着用户的手移动
用户拖动某个关节 → 那个关节被移动，其他部分自然跟随
用户推一下 → 生物获得一个初速度，慢慢停下来
```

**可以尝试的**：
- 拖拽头部
- 拖拽任意节段
- 拖拽肢体末端
- 物理风格的"推"和"扔"
- 多触点（如果支持）

---

### 模式 B：目标设定 - 给生物指路

用户设定目标，生物自己想办法过去。

```
用户点击画布 → 生物朝那个点移动
用户画一条路径 → 生物沿着路径走
用户放多个目标点 → 生物依次经过
```

**可以尝试的**：
- 点击设定目标
- 右键设定目标（避免误触）
- 长按拖动设定移动路径
- 多个目标点
- 目标可以移动

---

### 模式 C：参数调节 - 实时调整

用户调整参数，观察生物的变化。

```
滑块拖动 → 生物形态立即变化
预设按钮 → 切换到有趣的预设
随机按钮 → 生成随机的生物
```

**可以尝试的**：
- 实时预览（拖动就看到变化）
- 应用按钮（调好了再应用）
- 参数联动（改一个自动调其他）
- 预设保存和加载

---

### 模式 D：观察模式 - 袖手旁观

用户不直接控制，只是观察和欣赏。

```
用户看着生物自己漫游
有时放一些"刺激物"
有时改变环境
看生物如何反应
```

**可以尝试的**：
- 放置"食物"或"兴趣点"
- 放置障碍物
- 改变环境参数（重力、摩擦）
- 回放功能

---

### 模式 E：多生物互动 - 创造生态

用户创造和管理整个生物群体。

```
添加多个生物
看它们如何互动
调整它们的"性格"参数
观察生态的形成
```

**可以尝试的**：
- 快速创建多个生物
- 生物类型选择器
- 群体参数调整
- 关系可视化（谁在追谁）

---

## 反馈设计：让用户知道发生了什么

### 视觉反馈

**选中反馈**：
- 高亮轮廓
- 颜色变化
- 特殊的标记或光环
- 显示目标点和轨迹线

**状态反馈**：
- 生物的状态（追逐、漫游、放松）
- 当前"心情"或"情绪"
- 目标到达的进度

**交互反馈**：
- 点击时有视觉响应
- 拖动时有拖拽指示
- 参数调整时的预览效果

---

### 交互的流畅度

**响应要快**：
- 用户操作后立即有反馈
- 不要让用户等太久

**状态转换要平滑**：
- 从自动漫游到手动控制要自然
- 参数变化时形态渐变，不要跳变
- 目标切换时不要太突兀

**撤销和重试**：
- 可以撤销上一个操作
- 可以重置到初始状态
- 可以回退到之前的某个状态

## UI 布局的多种可能

### 布局 A：全画布沉浸

整个屏幕都是画布，UI 是临时浮出来的。

```
全屏画布
侧边滑出面板
点击画布边缘显示控制
手势召唤 UI
```

**适用**：想要沉浸感，观察为主

---

### 布局 B：经典三栏

左边参数，中间画布，右边列表。

```
┌─────┬─────────────┬──────┐
│参数 │  画布       │列表  │
│面板 │             │      │
└─────┴─────────────┴──────┘
```

**适用**：需要同时调整参数、观察、管理多个生物

---

### 布局 C：最小化 UI

画布为主，UI 很小或隐藏。

```
全屏画布
右下角几个小按钮
双击或手势唤出完整控制
```

**适用**：简洁风格，展示为主

---

### 布局 D：工作室风格

多个面板、窗口、工具。

```
很多可拖动的面板
可以自定义布局
工具齐全，像专业软件
```

**适用**：复杂的创作工具，高级用户

---

## 多设备考虑

### 触屏设备
- 手指操作的目标要足够大
- 手势操作（捏合缩放，滑动等）
- 长按和轻触的区别

### 键盘快捷键
- 常用操作有快捷键
- 快捷键可以自定义或提示
- 方向键控制生物移动

### 鼠标操作
- 左键和右键的区别
- 滚轮的使用
- 拖拽 vs 点击的区别

---

## 有趣的交互想法

### 环境影响
- 用户画出障碍物，生物绕行
- 用户画出地面，生物在上面走
- 用户改变"重力"，生物的移动方式变化

### 生物间互动
- 用户让两个生物"成为朋友"
- 用户建立等级关系
- 用户引导它们合作或竞争

### 时间控制
- 暂停和继续
- 慢动作
- 时间倒流（如果实现的话）
- 单步调试

### 创造性工具
- 画笔"画"出生物
- 雕塑工具调整形态
- 录制和回放功能
- 导出为 GIF 或视频

---

## 设计原则

### 简单直观
- 用户一看就知道怎么操作
- 常见操作很容易做到
- 复杂功能可以藏深一点

### 立即反馈
- 操作后立即看到结果
- 不要让用户猜测是否生效
- 反馈要清晰但不干扰

### 容错
- 用户可以撤销
- 有安全的重置方式
- 错误操作有提示或恢复方法

### 渐进式功能
- 新手有简单的模式
- 高级功能可以开启
- 教程或引导可以有，但不强迫

---

记住：交互设计没有标准答案，关键是让用户觉得有趣、想玩、愿意探索！
